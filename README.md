# Python Basics Journey

My Python learning journey, one script at a time, from Hello World to advanced concepts, updated as I learn.

## Topics covered
1. Hello World: your first program
2. Variables and Data Types: str, int, float, bool
3. Type Conversion: converting between types with str(), int(), float()
4. Multiple Assignment: assigning several variables at once
5. Tuple Unpacking: unpacking a tuple into variables

## How to run
Each file is standalone. Run any of them with:

    python 01_hello_world.py
